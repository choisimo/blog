# AI와 함께 읽기 — 10가지 디자인 프리뷰

첨부된 질문 카드 화면을 재구성한 독립 HTML 디자인 갤러리입니다. 제품의 React 화면이나 API를 변경하지 않습니다. 외부 라이브러리, 폰트 다운로드, AI 요청 없이 동작합니다.

## 열기

`index.html`을 브라우저로 직접 열거나 프로젝트 루트에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory design-previews/ai-reading
```

접속: <http://localhost:4317>

- 왼쪽 목록에서 10가지 프리뷰를 전환합니다. 휴대폰에서는 가로 목록입니다.
- **10개 한눈에 보기**: 실제 페이지를 축소한 썸네일에서 선택합니다.
- **이 디자인 선택**: 선택한 안을 이 브라우저에 저장합니다.
- **모바일**: 390px 기준의 프리뷰입니다. 브라우저가 더 좁으면 가용 폭에 맞춥니다.
- **HTML 다운로드**: 현재 디자인을 CSS와 JavaScript가 포함된 독립 HTML로 내려받습니다. 개인 메모는 다운로드에 포함하지 않습니다.
- URL의 `#design=7&device=mobile`처럼 디자인과 화면 크기를 지정할 수 있습니다.

## 디자인 구성

| 번호 | 디자인        | 정보 구조 / 탐색        | 상호작용 / 배치                |
| ---- | ------------- | ----------------------- | ------------------------------ |
| 01   | 조용한 집중   | 한 질문 중심, 순환 이동 | 중앙 단일 열, 근거 접기·펼치기 |
| 02   | 나란히 읽기   | 원문과 연결 질문        | 본문·탐색 병렬, 문장 선택      |
| 03   | 질문의 서재   | 질문 색인과 상세        | 목록·상세, 직접 항목 이동      |
| 04   | 생각의 계단   | 이해 → 의심 → 적용      | 단계 진행, 이전·다음과 마무리  |
| 05   | 이어지는 대화 | 시간순 질문과 예시 응답 | 대화 흐름, 추천 질문·자유 입력 |
| 06   | 관점의 보드   | 세 관점의 병렬 탐색     | 선택 카드와 아래 상세·입력     |
| 07   | 생각의 지도   | 중심 주장과 연결 질문   | 노드 선택과 하단 상세          |
| 08   | 나만의 여백   | 질문과 개인 기록        | 노트 양면, 메모 저장           |
| 09   | 손안의 읽기   | 본문과 보조 시트        | 시트 접기·펼치기, 하단 행동    |
| 10   | 두 관점 사이  | 지지와 반론 비교        | 나란한 비교, 입장 선택·질문    |

모든 예시 응답은 고정된 데모 문구입니다. 사용자 입력이나 메모를 실제로 분석하지 않습니다. 메모, 질문 초안, 질문 저장, 선택한 안은 로컬 저장소에 기록됩니다. 저장소가 차단된 경우에는 현재 탭의 메모리에서만 유지되며 화면에 이를 표시합니다. 대화형 예시 응답 이력은 프리뷰를 다시 열면 초기화됩니다.

## 구현

- `index.html`: 갤러리 문서와 선택·다운로드 도구
- `gallery.css`: 갤러리 및 반응형 레이아웃
- `gallery.js`: URL, 로컬 저장, 선택, 축소 미리보기, 다운로드
- `previews.js`: 10개 문서 템플릿, 테마, 샌드박스 내부의 데모 상호작용
- `verification/`: 실제 Chromium 렌더링과 확인 결과

프리뷰 iframe은 `allow-scripts allow-forms allow-downloads` 샌드박스에서 실행됩니다. 갤러리는 활성 iframe의 `postMessage`만 받고 값의 유형과 길이를 제한합니다. 입력은 `textContent`로 표시하고, 문서에 넣는 상태는 script 문맥에 맞게 이스케이프합니다.

## 확인

1100px, 390px, 320px의 30개 조합에서 가로 넘침, 질문 입력·예시 응답, 질문 전환, 저장을 확인했습니다. 선택·메모의 새로고침 유지, 모바일 URL 복원, 전체 보기, 독립 HTML 다운로드와 기록 유지, 상세 대화상자의 Escape 닫기를 확인했습니다. `verification/results.json`에 결과가 있습니다. 추가로 실제 갤러리 안의 320px 화면에서 10개 안의 입력·응답을 모두 확인했고, 키보드 모달 초점 복귀, 공백 입력 검증, 저장소 차단 시 안내, 파일 직접 열기도 확인했습니다. 이 결과는 `verification/additional-checks.json`에 있습니다. 이 확인은 디자인 데모 범위이며 제품 API와의 통합 검증을 포함하지 않습니다.
